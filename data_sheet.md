# Datasheet: Black-Box Optimisation (BBO) Capstone Dataset

Version: Final (Module 25)

## Motivation

This dataset was created to support a structured Black-Box Optimisation challenge as part of an ML training programme. It consists of iteratively collected query-response pairs used to train surrogate models (Gaussian Process and neural network) that guide sequential query selection toward the maximum of eight unknown functions.

Query-response data was generated by the learner through 13 rounds of weekly submissions (Modules 12-24). The black-box functions and portal infrastructure were created and maintained by the course team (Imperial College Business School / Emeritus).

## Composition

Each instance is a single query-response pair: a continuous input vector submitted to one of eight unknown functions, paired with the scalar output returned by the portal.

Fields per instance:
- function_id: integer 1-8
- round: integer 1-13
- query: hyphen-separated decimal string in [0,1], six decimal places
- output: scalar float returned by portal
- dimensionality: integer (2, 3, 4, 5, 6, or 8)

Function dimensionalities:
- F1, F2: 2D
- F3: 3D
- F4, F5: 4D
- F6: 5D
- F7: 6D
- F8: 8D

Dataset size: 13 observations x 8 functions = 104 total instances

Missing data: None. Every submitted query received exactly one output.

Gaps: Large regions of the input space remain unsampled, particularly for 6D and 8D functions. With 13 observations in an 8-dimensional unit hypercube, sampled volume represents a negligible fraction of the domain. This is a structural consequence of the query budget, not a collection failure.

Confidentiality: No personally identifiable information. The internal definitions of the eight black-box functions are withheld by the course team.

## Collection Process

Queries were generated using an evolving strategy across 13 rounds:

- Rounds 1-2: Space-filling exploration, heuristic alternating patterns, no surrogate model
- Rounds 3-4: GP surrogate introduced, Expected Improvement acquisition, NN surrogate for gradient guidance
- Rounds 5-7: Increasing exploitation for low-dim functions, structured exploration for high-dim
- Rounds 8-10: Strong exploitation for 2D/3D, boundary-probing for 6D/8D
- Rounds 11-13: Cluster-centroid targeting, PCA-informed dimension prioritisation, final confirmatory queries

Sampling strategy: Non-random, sequential, adaptive. Each query is informed by all prior observations. The dataset has strong sequential dependency and is biased toward high-performing regions identified in earlier rounds.

Timeframe: Approximately 13 weeks (Modules 12-24), one query per function per module.

## Preprocessing and Cleaning

- Input values formatted to six decimal places (portal requirement)
- No normalisation or scaling applied to inputs or outputs
- Raw data retained in full in data/queries/

## Uses

Intended uses:
- Sequential Bayesian Optimisation
- GP and neural network surrogate model training
- Exploration-exploitation strategy analysis
- Surrogate surface visualisation

Not suitable for:
- Training models intended to generalise beyond the queried domain
- Drawing inferences about the true functional form of the functions
- Benchmarking without accounting for sequential dependency structure

## Distribution

Stored in and distributed via the learner's public GitHub repository as part of the final capstone submission. The portal and functions are proprietary to the course team and are not distributed.

## Maintenance

Query dataset maintained by the learner in their GitHub repository. Portal and functions maintained by the course team.

## Key Assumptions and Limitations

- Stationarity: RBF kernel assumes uniform function variation. Sharp peaks will be underestimated.
- Determinism: same input always returns same output. If noise exists, exploitation may chase artefacts.
- Selection bias: dataset heavily biased toward regions identified as high-performing in early rounds.
- Large unsampled areas remain, particularly for 6D and 8D functions.
