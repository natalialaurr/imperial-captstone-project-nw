Black-Box Optimisation (BBO) Capstone Project

A sequential, model-guided approach to optimising eight unknown functions using Gaussian Process surrogates, acquisition functions, and SVM-informed region classification.

Non-Technical Explanation of Your Project
Imagine you are trying to find the highest point on a hilly landscape, but you are blindfolded — you can only feel the ground directly beneath your feet at each step. This project tackles exactly that kind of problem, known as black-box optimisation. There are eight hidden mathematical functions, and the goal is to find the input values that produce the highest possible output, without ever seeing the function itself. By submitting carefully chosen query points and observing the returned values, a machine learning model learns the shape of each function over time and uses that knowledge to make smarter and smarter guesses — homing in on the peak with as few steps as possible.
Data
The dataset consists of query-response pairs generated by submitting input coordinates to the BBO capstone project portal. Each query point is a vector of continuous values in [0, 1], formatted to six decimal places, and the portal returns a scalar output from the corresponding hidden function. There are eight unknown functions ranging in input dimensionality from 2D to 8D. Data is collected iteratively across Modules 12–24, with one query per function per module. Full metadata is documented in data_sheet.md.
Model
The surrogate model is a Gaussian Process (GP) Regressor from scikit-learn, fitted to the growing set of observed query-response pairs after each round. A GP was chosen because it provides both predictions and calibrated uncertainty estimates — a critical property for sequential optimisation under uncertainty. The uncertainty estimates feed directly into an Expected Improvement (EI) acquisition function, which selects the next query point by balancing predicted output quality with how uncertain the model is in that region. From Round 4 onward, a neural network surrogate (PyTorch) was introduced for gradient-informed query selection in higher-dimensional functions. Full model details are documented in model_card.md.
Hyperparameter Optimisation
The GP uses an RBF kernel combined with a WhiteKernel to account for noise. Both the length scale and noise level are optimised automatically at each fitting step by maximising the log marginal likelihood, using scikit-learn's built-in optimisation with n_restarts_optimizer=5. The EI acquisition function threshold parameter ξ is set per function: 0.005 for well-characterised lower-dimensional functions (exploitation) and 0.05 for higher-dimensional functions (exploration).
